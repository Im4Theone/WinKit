Tour

A closer look.

Features

Everything Windows keeps
in a dozen different places.

System overview

CPU, memory, GPU, storage, network, Windows build and uptime in one place, with meters that change colour as they fill. Instead of Settings, Task Manager and winver.

Diagnostics

Eleven checks across connectivity, drivers, disk health, services and Windows Update, reported in plain language rather than error codes, with a one-click fix wherever one exists.

Processes & services

A live process list with real memory and CPU for every process, sorted by memory like Task Manager, plus services and startup items in the same window.

Disk usage

See what is taking your space, drive by drive and folder by folder. Junctions and cloud-only files are not counted twice, and the scan can be cancelled any time.

Network tools

Ping, traceroute, DNS lookup, IP configuration, open ports, Wi-Fi details and a connection test, next to maintenance actions like flushing DNS and resetting adapters.

Cleanup

Scan temporary files, the thumbnail and Windows Update caches and the Recycle Bin, see what each category holds, and reclaim only the space you choose to.

Administrative utilities

Installed applications with clean uninstall, an environment variables editor and a hosts file editor, elevated only when a task needs it.

Health report

One plain-text summary of your PC for a friend, a forum or a support desk. Computer name, addresses and Wi-Fi names are left out unless you include them.

Made to be used

Quick Open jumps to any page or action. Every list is searchable, values copy with a click, and the window reopens exactly where you left it.

Principles

Small, private, honest.

Small on purpose

The whole app is one executable under 1 MB. It idles at almost no CPU, and stops polling entirely while minimised.

Private by default

Settings and history stay on your machine under %LOCALAPPDATA%\WinKit. No account, no cloud sync, no telemetry. Crash reports are only sent if you press Send.

No fake optimisation

Every action is a real, explainable operation. Anything destructive asks first, and WinKit never follows a link or junction out of the folder it was asked to clean.

FAQ

Questions, answered.

Windows says the publisher is unknown. Is it safe?

WinKit is not code-signed yet, so Windows SmartScreen may show an "unknown publisher" notice the first time you run it. The source code is public on GitHub, and every download has a SHA-256 checksum you can verify below.

Does it need administrator rights?

No. It starts as a normal app. A few actions, such as resetting the network stack or editing the hosts file, ask Windows for approval when you use them. Checks that need those rights say so instead of guessing.

What does it send over the internet?

Nothing on its own, apart from an optional check for new versions against GitHub Releases, which you can turn off. There is no account and no telemetry.

Portable or installer?

The portable file runs from anywhere and leaves nothing behind. The installer adds a Start Menu shortcut and an uninstaller, and both update themselves from GitHub Releases after a checksum check.

It says WebView2 is missing.

WinKit's interface uses the Microsoft Edge WebView2 Runtime, which Windows 11 and current Windows 10 already include. If yours is missing, WinKit offers the official download link.

Where is my data stored, and how do I remove it?

Settings, themes and history live in %LOCALAPPDATA%\WinKit. Delete that folder to remove everything. The installer's uninstaller also removes the start-with-Windows entry.

Does it replace Task Manager?

It covers a lot of the same ground in a calmer window, and adds disk usage, Wi-Fi, diagnostics and a health report. It does not try to be a performance profiler.
